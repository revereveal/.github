## Three platforms

### Revasser Commercial Ops
Back-office operating system + storefront + shipping + live commercial services. Powers [revaddress.com](https://revaddress.com).

- **`revasser-operating-system`** — Back-office OS. USPS shipping API, printing, fax. 293 tests, 7 CF Workers, 41 routes. Live.
- **`revasser-site-build`** — Revasser Shopify theme and storefront.
- **`revasser-edge`** — Evidence Ops Desk. Comment packs, $497 anchor.
- **`slack-mcp-hosted`** — Hosted Slack MCP at [mcp.revasserlabs.com](https://mcp.revasserlabs.com). Stripe live, Solo $19/mo, Team $49/mo.
- **`slack-mcp-server`** — Public npm [`@jtalk22/slack-mcp`](https://www.npmjs.com/package/@jtalk22/slack-mcp). Awareness tier for hosted.
- **`usps-v3`** — Python/Node/PHP SDKs for USPS Web Tools v3. OAuth 2.0, address validation, tracking.
- **`grant-pipeline`** — Grant and credits pipeline across Azure, OpenAI, Anthropic, AWS, Microsoft.

### RevasserKernel
Semantic research infrastructure. Powers [revasserkernel.com](https://revasserkernel.com).

- **`MRIworkarounds`** — RevasserKernel cerebellar research portal. 10,000+ papers across 7 databases (PubMed, PMC, bioRxiv, medRxiv, arXiv, J-STAGE, Semantic Scholar), 13 research domains. Cloudflare free tier, $0/month. TrialFinder API + research portal tiers.
- **`codex-otter-automation`** — The Kernel. 668 therapy sessions, 53,990 segments, ARCSI pattern taxonomy, Resolution UI for labeling. The explicit-training corpus for cross-domain pattern transfer.

### Revasser Runtime Platform / CLS
Operator plane, hosted runtime, portable local tooling, narrative architecture.

- **`claudejtalk22`** — Revasser Runtime Platform. Hosts [api.revasser.ai](https://api.revasser.ai). 10 live operator agents: founder, evidence, prompt-mastery, prompt-buckets, ore-activation, disagreement-pack, azure-overnight, promotion, workflow, training-candidate. Mini nonstop executor. Claude Code Tier 0-4 as substrate.
- **`portfolio`** — Infrastructure hub. 55 Cloudflare Workers, 7 Pages, canonical Claude Learning System runtime + daemon.
- **`claude-brain`** — Portable ~/.claude operating system. v4.2.22.
- **`codex-control-plane`** *(after move)* — Portable ~/.codex. Parallel to claude-brain for OpenAI Codex CLI.
- **`north-star`** — Architectural narrative, vision docs, film production.
- **`claude-cookbooks-revasser`** — MCP Router v3.0 + synthesis infrastructure.
